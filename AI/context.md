# 🗂️ Project Context — 客服考核遊戲系統

> 每次開啟新的開發對話前，AI 請先閱讀此檔案以理解專案背景。

---

## 專案一句話描述

一套給客服新人使用的**線上考核遊戲**，以楓之谷像素點陣風格為介面主軸，整合 Google Sheets 作為題庫來源與成績輸出，並透過排行榜機制激發學習競賽感。

---

## 目標用戶與角色

| 角色 | 主要任務 |
|------|---------|
| **考生**（客服新人） | 登入後進行考試、查看自身成績、回顧錯題、瀏覽排行榜 |
| **主管** | 批改申論題（含評分 + 評語）、管理題庫、查看所有考生成績 |
| **系統管理員** | 管理使用者角色與權限、設定系統參數（Google Sheets 連結等） |

---

## 核心功能清單

1. **身份系統**：Google OAuth 登入 + 手動填寫顯示名稱（Email 為唯一識別碼）
2. **考試系統**：
   - 綜合模式（選擇 + 問答，20 題，每題 5 分鐘，可無限刷題）
   - 申論模式（10 題，每題 10 分鐘，同時只能一場，每月至少一次）
3. **計時機制**：全場計時（100 分鐘）+ 每題獨立倒數；以伺服器時間為準
4. **題庫整合**：從 Google Sheets 手動同步；題目隨機抽取，同場不重複
5. **批改後台**：主管逐題打分（滿分 100，每題 10 分）+ 寫評語，批改後推送系統通知
6. **錯題回顧**：查看歷次考試每題的作答、正確答案與評語
7. **排行榜**：以最高分排序，全員公開，前三名像素獎牌特效
8. **成績匯出**：自動寫入 Google Sheets（欄位：Email、顯示名稱、日期、模式、得分、總分、通過與否）
9. **通過門檻**：90 分（綜合 + 申論合併計算）

## 設計規範

| 項目 | 規格 |
|------|------|
| 視覺風格 | 楓之谷像素點陣風格（Pixel Art） |
| 主色調 | 暖橘 / 楓葉紅 / 天空藍 |
| 字型 | 像素字型（Cubic 11 / Zpix，需支援中文）+ 現代輔助字型 |
| 動畫 | hover 光暈、倒數條動態、角色陪考動畫 |
| 音效 | ❌ 不納入任何版本 |
| 響應式 | Desktop / Tablet / Mobile 全支援 |
| 語言 | 繁體中文（預留 i18n 架構供未來英文擴充） |

---

## 關鍵業務規則（開發時必須遵守）

- 申論題同時只能存在一場（含待批改狀態）
- 綜合模式可無限重複作答，排行榜取最高分
- 申論模式每位考生每月至少提交一次，未提交時首頁顯示提醒
- 計時以**伺服器時間**為準（防止前端操控）
- 題庫同步為**手動觸發**（由主管或管理員操作）
- 排行榜**全員公開**，不分部門 / 梯次
